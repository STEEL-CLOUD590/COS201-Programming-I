# COS201 Programming I

## Project Title
Java Programming Exercises for COS201

## Introduction
This repository contains a set of Java programs developed as part of the COS201 Programming I coursework. The exercises are designed to strengthen fundamental programming skills, including user input handling, arithmetic operations, and basic data processing. Each program demonstrates practical application of core Java concepts in a simple and structured format.

## Aim of the Project
The aim of this project is to apply the principles of programming in Java to solve basic computational problems. The exercises included in this repository focus on using variables, arithmetic operators, console input, and formatted output to produce correct and readable results.

## Programs Included

### 1. SimpleCalculator
This program accepts two numbers from the user and performs the following operations:
- Addition
- Subtraction
- Multiplication
- Division

The program also checks for division by zero and displays a suitable message if the denominator is zero.

### 2. AverageCalculator
This program reads three scores entered by the user, calculates their total, and determines the average score. The result is displayed in a neat and readable format.

### 3. ItemCost
This program takes the quantity of an item and its unit price as input, then calculates the total cost of the items purchased. The output is displayed in a formatted monetary value.

## Tools and Technologies
- Java Programming Language
- Java Development Kit (JDK)
- Command-line interface (CLI)

## How to Run the Programs
To compile and run a Java program in the project, use the following commands in the terminal:

cd week03
javac SimpleCalculator.java
java SimpleCalculator

Similarly, the other programs can be executed as follows:


javac AverageCalculator.java
java AverageCalculator


javac ItemCost.java
java ItemCost

## Program Functionality and Output
Each program interacts with the user through the console, collects input values, performs the required calculations, and prints the final results in a clear format. The applications are designed to be straightforward and easy to understand for beginners learning Java programming.

## Learning Outcomes
This project demonstrates the application of the following concepts:
- Java syntax and structure
- Data types and variables
- Console input using `Scanner`
- Arithmetic expressions
- Conditional statements
- Output formatting using `printf`

## Conclusion
The Java programs in this repository provide practical experience in solving simple computational problems using foundational programming concepts. They serve as a useful introduction to Java programming and help reinforce the basic principles taught in COS201 Programming I.
